# Note on scikit-learn
# -------------------
# The duplicate-detection design calls for TF-IDF + cosine similarity. Rather
# than pull in scikit-learn and scipy for two functions applied to ~26 short
# strings, both are implemented directly in NumPy in
# `anomaly_engine/text_similarity.py`, matching scikit-learn's default
# TfidfVectorizer behaviour (smooth IDF, L2 row normalisation, the
# `(?u)\b\w\w+\b` token pattern). This keeps the dependency footprint small and
# the arithmetic auditable. See that module for the full note.
